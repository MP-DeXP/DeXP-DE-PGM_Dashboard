# PGM Ops 인수인계 메모

## 이번 반영 범위

- 상단 개요를 `Daily / Weekly / Monthly` 3분할 비교판으로 재구성했습니다.
- 기간별 카드 안에서 역할 기여 전체 랭킹을 함께 보여주고, 1위 역할을 가장 강하게 읽히도록 바꿨습니다.
- 역할 표기는 UI 전반에서 아래 한국어 라벨로 통일했습니다.
  - `entry` → `첫구매 유도`
  - `expansion` → `단골 유도`
  - `return` → `반복 구매`
  - `convergence` → `구매 집중`
- 메인 2행을 `브랜드 전체 구조` full-width 블록으로 올렸습니다.
- `브랜드 전체 구조`에서 역할별 현재 상품 목록과 `7일 / 30일 / 90일` 비교 슬롯을 함께 보이도록 바꿨습니다.
- 좌측 상품 선택은 큰 갤러리가 아니라 작은 보조 탐색 리스트로 축소했습니다.
- 상품 썸네일과 상세 링크를 계속 노출하도록 유지했습니다.

## 중요 제약 사항

- 매출 source인 `silver_fact_product`는 tenant 기준 장기 이력이 충분합니다.
- 하지만 역할 source인 `gold_pgm_product_demand_gravity`는 현재 tenant 기준 `2026-04-06`부터 `2026-04-17`까지 12일만 확인됩니다.
- 보조 role source인 `gold_pgm_scored`도 `2026-04-05`부터 `2026-04-17`까지 13일만 확인됩니다.
- 그래서 `7일 역할 구성 변화`는 실관측 기반 해석이 가능하지만, `30일 / 90일 역할 구성 변화`는 완전한 same-date historical role이 아니라 부분 관측 + window metric 보정이 섞인 상태입니다.
