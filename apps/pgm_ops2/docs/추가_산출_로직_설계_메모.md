# 추가 산출 로직 설계 메모

## Revenue / Queue 트랙

- source 조합
  - `dma.silver_fact_product`
  - `dma.gold_purchase_analysis_daily`
- 신규 mart
  - `mart_product_revenue_windows`
  - `mart_product_priority_basis`
  - `mart_priority_queue_snapshot`
- 로직 성격
  - rolling 집계
  - 직전 동일 길이 window 비교
  - queue 단계 판정 규칙
- 상태
  - source 충분 시 `available`

## Role taxonomy 트랙

- source 조합
  - `dma.gold_pgm_scored`
  - `dma.gold_pgm_product_demand_gravity`
  - `dma.gold_pgm_entry_to_expansion_transition`
  - `dma.gold_pgm_product_transition_edge`
  - `dma.gold_pgm_return_gravity_loop_detail`
  - `dma.gold_pgm_basket_gravity_detail`
- 신규 mart
  - `mart_product_role_taxonomy_daily`
- 로직 성격
  - 단순 집계 + 새 taxonomy 규칙 정의
  - same-date snapshot only
- 상태
  - 관측 있으면 `available`
  - 일부 근거 부족이면 `limited`
  - 관측 부재면 `unavailable`

## Brand Score high-similarity 트랙

- source 조합
  - `dma.gold_pgm_scored`
  - `dma.gold_pgm_product_demand_gravity`
  - `dma.gold_pgm_basket_gravity_detail`
  - 제한적 예외 source로 재구성한 basket/event intermediate
- 신규 mart
  - `mart_brand_score_reconstruction`
  - `mart_brand_score_validation_status`
- 로직 성격
  - 새 규칙 정의 필요
  - core 산식 참고
  - exact parity 비보장
- 상태
  - 핵심 축 누락 시 `unavailable`
  - basket/event 부족 시 `limited`
  - 5축 대부분 재현 시 `provisional`
  - 입력/축/산식 유사도 높으면 `near-core`
