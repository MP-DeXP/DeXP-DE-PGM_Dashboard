## 계약 규칙

- 기본 grain은 `date + product_id` 또는 `product_id`만 사용한다.
- rolling 비교는 항상 직전 동일 길이 window 기준이다.
- Role은 same-date snapshot only를 지킨다.
- Brand Score UI 상태값은 `unavailable / limited / provisional / near-core`만 사용한다.
- 상품 이미지 필드는 `product_image_url` 하나로 통일한다.
- `product_image_url`는 `products.list_image`에서만 채운다.
- 이미지 값이 비어 있으면 UI에서 플레이스홀더로만 처리한다.
- UI는 큐, 구조 맵, 상세 보기, 정의 보기, 데이터 상태 5화면만 직접 소비한다.

## 상품 이미지 계약

- 필드명: `product_image_url`
- 타입: 문자열
- 허용값: URL 문자열 또는 빈 문자열
- source 범위: `raw_rosetta.products.csv`
- 선택 규칙: `list_image`를 그대로 사용한다.
- 조인 키: `product_id`
- 금지 사항: `detail_url`을 이미지처럼 사용하거나, 상품 source 밖의 다른 테이블 값으로 추정 보정하지 않는다.

### UI 반영 원칙

- 우선순위 큐, 구조 맵, 상세 보기의 상품 선택 목록, 상세 헤더는 모두 `product_image_url`만 사용한다.
- 이미지가 비어 있거나 로드에 실패하면 동일 크기 플레이스홀더를 노출한다.
- 대체 이미지를 추정 생성하지 않는다.
- 이미지 alt는 상품명이 있으면 상품명, 없으면 `상품 이미지`를 사용한다.
