## 계약 규칙

- 기본 grain은 `date + product_id` 또는 `product_id`만 사용한다.
- rolling 비교는 항상 직전 동일 길이 window 기준이다.
- Role은 same-date snapshot only를 지킨다.
- Brand Score UI 상태값은 `unavailable / limited / provisional / near-core`만 사용한다.
- UI는 큐, 구조 맵, 상세 보기, 정의 보기, 데이터 상태 5화면만 직접 소비한다.
