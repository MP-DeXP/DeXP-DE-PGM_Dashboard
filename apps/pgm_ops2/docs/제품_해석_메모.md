# 제품 해석 메모

## PRD 기준 제품 정의 요약

- 제품명은 `PGM 운영 툴`, 앱명은 `pgm_ops2`다.
- 첫 화면은 대시보드가 아니라 상품 우선순위 큐다.
- 우선순위는 단일 점수 대신 Revenue 이유, Role 이유, Brand Score 상태를 분리해 보여준다.
- v1 우선순위 단계는 `즉시 확인 / 주의 관찰 / 정상 유지` 3단계만 사용한다.
- Revenue는 결과 축이며, 기본 비교 기준은 직전 동일 길이 rolling 기간이다.
- Role은 해석 축이며 `첫구매기여 / 재구매확장기여 / 반복구매기여 / 동시구매기여` taxonomy를 사용한다.
- Brand Score는 약한 보정 신호 축이지만, 이번 v1 큐 랭킹에는 연결하지 않는다.

## 이번 앱에서 반드시 구현해야 할 것

- 상품 기준 우선순위 큐
- rolling Revenue 비교와 reason stack
- same-date role snapshot 기반 taxonomy 분류
- 구조 맵, 상세 보기, 정의 보기, 데이터 상태 화면
- freshness, missing, unavailable 상태 노출
- Brand Score 재현 수준 패널과 정의/제약 설명

## 이번 앱에서 명시적으로 제외할 것

- 기존 `pgm_ops` 레이아웃/카드/산출물 계약 재사용
- fixture를 truth처럼 노출하는 화면
- Brand Score를 메인 우선순위 축으로 쓰는 랭킹
- source에 없는 history를 가정한 장기 role 비교
